# Reserva_Vinos
Proyecto realizado para mi carrera Desarrollo de Software.
Esta pagina web consiste en un sistema que gestione las reservas de vino para un local. Una vez llegado a la tienda fisica, se muestra la reserva y se pagan los vinos. (Se puede implementar cualquier sistema de pago para realizar E-Commerce)
Tecnologías usadas para el FrontEnd: HTML, CSS, JavaScript
